# Task Closeout SOP

1. Run the final minimum verification commands.
2. Clean up task notes so another agent can understand the result.
3. Create `summary.md` in the task folder with goal, changes, verification, and open issues.
4. Ensure outputs are in `outputs/` and stable docs are in `docs/`.
5. Move completed or abandoned tasks into `archives/` when appropriate; archived task folders remain private to the workspace root repository.
6. Do not archive secrets or unnecessary temporary files.
7. Publish a selected task only through an independent Git repository inside that task directory.
